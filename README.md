# 🎓 Academic Projects

Repository containing the public versions of my Bachelor's and Master's theses completed during my **Computer Engineering Degree** and **MSc in Cybersecurity & Data Intelligence** at the **University of La Laguna**.

Both documents have been edited to remove personal information while preserving their complete technical content.

> ⚠️ Note: Both theses are written in Spanish. A brief summary in English is included within each document.

---

# 📚 Contents

## 📗 Master's Thesis (TFM)

### Experimental Evaluation of WiFi Security

This project presents an experimental evaluation of modern WiFi authentication mechanisms, comparing **WPA2-Personal**, **WPA3-Personal**, and **WPA2/WPA3 Transition Mode** using a fully reproducible wireless laboratory.

### Main topics

- IEEE 802.11
- WPA2
- WPA3
- SAE Authentication
- Wireless Security
- Wireshark
- Aircrack-ng
- Hashcat
- hcxdumptool

## 📘 Bachelor's Thesis (TFG)

### Exploitation of Red Team Techniques

This project focuses on the practical application of penetration testing methodologies through hands-on laboratories covering Linux, Windows and Web Application Security.

### Main topics

- Ethical Hacking
- Penetration Testing
- Vulnerability Assessment
- Web Security
- OWASP Web Security Academy
- Burp Suite
- Linux Security
- Windows Security
- TryHackMe Labs
